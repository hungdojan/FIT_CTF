FIT-CTF documentation

FIT-CTF is a container-oriented Capture The Flag (CTF) platform developed at FIT BUT (Brno University of Technology). It lets operators run classroom or competition-style CTF events where each participant gets isolated container instances, while shared infrastructure (login nodes, admin services) runs at the project level.

The platform is built around Podman and podman-compose (Docker is also supported as a container backend). State is stored in MongoDB; challenge environments are defined as scenarios compiled from Jinja2 templates into Docker Compose files.
